## 別のマシンのアプリを使う

両方のマシンに[CLIをインストール](../../start/installation/)します。アプリのあるマシンで実行してください。

```sh
omochi-ui gateway --remote --pair --name workstation
```

Hubを使うマシンで、表示された招待リンクを登録します。

```sh
omochi-ui pair --name workstation
# 招待を標準入力へ貼り付け、Ctrl+D。
omochi-ui hub
```

Gatewayが表示する招待リンクは、どちらも`pair`へ貼り付けられます。招待は3分間有効で、ひとつのHubを登録できます。別のHubには新しい招待を発行してください。標準入力を使うと招待がシェル履歴に残りません。

登録したHubは、そのGatewayが公開するすべてのアプリ・操作・リソースにアクセスできます。招待は非公開の経路で渡し、利用中は両方のマシンでサービスを動かしておきます。登録後はIPアドレスを入力せずに再接続できます。

## ホストされたブラウザーから接続する

Hubのあるマシンで実行します。

```sh
omochi-ui hub --remote
```

ローカル画面 **http://127.0.0.1:5555/** の接続セクションで **オーナーブラウザを登録** を選び、対象ブラウザーでリンクを開いて承認します。招待は3分間有効です。登録後のオーナー権限は、Hub側で取り消すまで続きます。利用中はHubを起動したままにします。

オーナーは全ダッシュボード、ビュー・接続元の変更、アプリ操作、共有管理、Gateway登録を行えます。オーナーの登録・取り消しはローカル画面で行います。ボードひとつだけを見せる場合は[ダッシュボード共有](../dashboards/#保存したダッシュボードを共有する)を使います。

このブラウザーからGatewayを追加するには、アプリ側で`gateway --remote --pair`を実行し、表示されたHTTPSリンクかQRを開きます。接続先のオーナーHubを選び、**このハブに追加** を押してください。共有リンクで接続した利用者はGatewayを追加できません。

ブラウザーの接続情報は保存され、次回も同じブラウザーから接続できます。ブラウザーの保存データを消した場合は、新しいオーナー招待で登録し直します。登録途中で切断した場合は[トラブルシューティング](../../understand/troubleshooting/#gateway登録の途中で切断した)を参照してください。

## モバイル・デスクトップアプリから接続する

[Omochiアプリ](../mobile/)ではGatewayの招待を **この端末に追加** するか、外部Hubのオーナー・共有リンクを開きます。ブラウザーで使ったオーナー招待は再利用できないので、アプリ用に新しい招待を発行してください。

## ネットワークを設定する

通常は接続先のアドレスを自動で探し、直接接続できない場合はリレーを使います。独自のリレーには`--relay URL`、LAN内だけで使う場合は`--offline`を指定します。オプションの詳細は[設定](../../reference/configuration/)を参照してください。

ホストされたブラウザーへの接続に、HubのHTTPポートの外部公開は不要です。既定の`127.0.0.1`バインドを維持してください。`hub --remote`と`--offline`は併用できません。

## 接続を確認・取り消す

```sh
omochi-ui status
omochi-ui trust list
omochi-ui trust forget NAME_OR_ENDPOINT_ID
```

Gatewayのアプリへのアクセスを取り消すには、そのGatewayで`trust forget`を実行します。Hubのオーナー権限はローカル画面、共有リンクはボードの共有画面から取り消します。これらの権限は別々に管理します。

クライアント側で接続記録を削除するだけでは、接続先のアクセス権は取り消せません。送達済みのデータや実行済みの操作も取り消せません。取り消しに失敗した場合は[トラブルシューティング](../../understand/troubleshooting/#アクセス権の取り消しがエラーになる)を参照してください。
